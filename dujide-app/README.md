# 都记得 · 应用原型

《都记得》（We Remember）的可交互前端原型。零依赖、无构建：直接打开 `index.html` 就能跑。

规格来源：[`../docs/都记得-PRD.md`](../docs/都记得-PRD.md)（V1.1）。
容器与动效数值来源：[`container-motion-materials.md`](container-motion-materials.md)。

## 这是什么产品

不是家务清单，是**家庭责任的所有权交接系统**。

它先是一个通用 Agent，你可以拿它改稿、问天气、随口聊。只有在你用密钥进了一个家之后，才多出「家里的那一层」：把散落在对话里的家庭事务识别出来，标注出**谁在发现问题、谁在记截止时间、谁在做安排、谁只是执行、谁在跟进**，然后提议把一整块责任交接给明确的主人。

## 怎么跑

```bash
# 方式一：直接打开
open index.html

# 方式二：起个静态服务
python3 -m http.server 5180
# 然后访问 http://127.0.0.1:5180/
```

左栏是演示控制（不属于应用本身）：可以切换演示谁（妈妈 / 爸爸 / 奶奶），也可以按 11 步脚本走。右侧是一部手机，就是应用本身。

## 应用结构

手机上只有三个功能页：

| 页 | 内容 |
| --- | --- |
| 对话 | 落地页。没进家之前就是个普通助手；进家后多出家庭群 |
| 家里 | 进去要先输密钥。解锁后是「这周只有你在记得」+ 没人管的责任 + 全家待办表 + 我负责的 |
| 连接 | 连接中心。当前只做个人微信私聊和第三方机器人签名接口 |

## 值得亲手点的地方

- **第 1 步的对话**：改周报、问晚饭吃什么。这些都不进任何家庭记录。
- **第 5 步在奶奶那边**：她说「腿又疼了」，Agent 先问她同不同意。三个选项都试试，选「先别说」之后切到妈妈，那句话真的不存在。
- **第 7 步的交接包**：缺「报告在哪」和「要不要空腹」两项，状态就停在交不过去。所有权不转移。
- **第 9 步的播报回执**：设备说收到了，但没观察到它真的播，所以只算「已接受」。超时该往下找人还是会找 —— 播了不等于她听见了。
- **任意首页底部的「这不是我的情况」**：能看到产品为什么给你这个版式，以及一键换掉。

## 文件

```
index.html    演示外壳 + 一部手机
styles.css    设计系统。配色取自新 UI 图，容器与动效取自材质文档
data.js       数据模型 + 派生计算。所有数字都由数据算出，没有一个写死
app.js        渲染、状态机（交接 / 看护 / 播报）、演示脚本
qa/shot.mjs   用 CDP 驱动无头 Chrome 截图并采集度量
```

## 自动检查

```bash
python3 -m http.server 5180 &     # 先起服务
node qa/shot.mjs 0                # 截初始态
node qa/shot.mjs 7                # 截任意演示步骤
```

脚本会输出并断言这几项：

- 手机屏内**横向溢出**（横向滚动容器除外）
- 老人侧**正文字号**（要求 ≥ 20px）与**点击区**（要求 ≥ 60×60，量的是布局像素而不是舞台缩放后的尺寸）
- **JS 运行时错误**
- **界面禁用词**：`primary` / `partner` / `subject` / 主责任人 / 被看护人 / 共同生活成员。
  这些词一个都不许出现在界面上，原因见 PRD 6.5 —— 给人定性会造成真实伤害，而且用户不需要理解产品的责任模型。
  抽屉、空态、Toast 这些默认不渲染的地方最容易漏，所以要跨交互状态检查，不能只扫首屏。

## 这个原型刻意暴露的工程细节

1. **五阶段归属是任务上的一等字段**，责任集中度表由 `tasks` 现场统计，不是模型现场生成的文案。可以当场追问任意一格。
2. **交接在信息不全或缺一方确认时停住**，所有权不转移。不允许出现「以为交出去了，其实没人管」。
3. **看护升级链是纯状态机**，那段代码里没有任何模型调用。AI 只负责把一句话抽成规则草稿，而且必须有人点头才生效。
4. **播报有五种交付状态**，其中「已接受但没观察到播放」单独一档。任何一种都不能满足「她回应了」。

## 边界

这是产品交互原型，不是生产实现。

- 见证 Agent 用的是关键词启发式，不是大模型。生产环境必须是大模型 + JSON Schema 校验 + 失败降级为待人工确认。
- 没有后端。密钥校验、会话签发、限流、跨端同步都需要服务端，静态原型做不到。
  `DEMO-HOME` 是**公开演示码，不是真实密钥**。
- 播报走的是假适配器，刻意落在「已接受但没观察到播放」以说明那一档为什么必须存在。没有真机调用。
- 连接中心只展示已经定好的接入边界。没有配置任何平台凭据，也没有启动任何消息适配器。
- 不是医疗设备。不看病、不替代急救、不做用药剂量建议。
