# Static SVG Avatar Library

This runtime directory contains the six roles in two static forms:

- `family.svg`: family-life visual form
- `work.svg`: professional visual form

The 12 files are default avatar choices only. They do not select a workspace, change identity, or grant permissions. Animated `family-to-work.svg` and `work-to-family.svg` files are intentionally excluded.
